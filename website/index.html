核心哲學

專為流暢專注、極速與靜音而生

每一個互動與技術細節，皆為消除 macOS 點對點檔案傳輸的阻力而量身定制。

🎯

FormatWheel 徑向操作 UX

無需在雜亂視窗中尋找接收端。拖曳檔案時按住 ⌃ Control，即在游標處彈出 540px 輪盤，甩入 45° 扇區放手即可完成傳送。

⚡

純 Swift 原生傳輸引擎

以 Apple 原生 Network.framework 與 AWDL 重構。零 C/Python FFI 包袱，秒速冷啟動，維持常數 $O(1)$ 記憶體安全邊界。

🤫

完全靜音原則 (Total Silence)

全專案嚴格零音效檔案、零系統音訊 API 呼叫。無突兀提示音與警示音，為專業創作者與工程師打造不被干擾的沉浸式工作流。

🛡️

透明誠實的安全邊界

透過 TLS 葉憑證釘選（Leaf Pinning）確保連線安全，絕不依賴或偽造 Apple ID 憑證鏈，嚴禁假進度條，不破壞系統 SIP 或 Keychain。

運作原理

AirDrop 傳輸管線時序

AirDrop Wheel 如何在無需第三方雲端伺服器的情況下完成點對點連線與傳輸。

01

AWDL 介面直連綁定

直接綁定 Apple Wireless Direct Link (awdl0) 介面，開啟點對點 IPv6 鏈路本地多播探索。

02

DNS-SD Bonjour 掃描

掃描 _airdrop._tcp 服務，即時解析目標裝置型號（iPhone、MacBook、iPad）並自動過濾排除本機。

03

TLS 握手與葉憑證釘選

經由 POST /Discover 握手並提取鎖定對端 Leaf 公鑰，防止後續 /Ask 與 /Upload 遭受中間人掉包。

04

POSIX ODC CPIO 串流分塊

以 64 KiB 分塊串流發送標準 CPIO 歸檔（POST /Upload），全過程維持常數 $< 15\text{MB}$ 記憶體極限。

快速上手

安裝與執行 AirDrop Wheel

適用於所有搭載 macOS 14.0 Sonoma 或更高版本的 Mac。

下載適用於 Apple Silicon (M 系列) 及 Intel Mac 的通用二進位版本：

下載最新發行版 (.app)

1. 將 AirDrop Wheel.app 拖移至 /Applications（應用程式）目錄

2. 啟動並依系統提示授予 輔助使用 與 區域網絡 權限

3. 將接收端裝置之 AirDrop 設定為 「所有人（10 分鐘）」

4. 拖曳檔案並按住 ⌃ Control 即可呼喚輪盤！

使用 macOS 內建 Xcode Command Line Tools 複製並一鍵編譯：

git clone https://github.com/Manfredsun/airdrop-wheel.git
cd airdrop-wheel
bash scripts/build_release.sh

編譯完成並已通過穩定代碼簽署的產物將產出於 dist/AirDrop Wheel.app。
