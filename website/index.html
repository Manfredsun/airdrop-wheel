Core Principles

Engineered for Flow, Speed & Silence

Every detail is designed to remove friction from peer-to-peer file transfer on macOS.

🎯

FormatWheel Radial UX

No window hunting. Hold ⌃ Control during file drag to summon the 540px radial wheel directly at your cursor. Flick into any 45° sector to dispatch instantly.

⚡

Pure Swift Engine

Rewritten from scratch with Apple's native Network.framework and AWDL. Zero C/Python FFI dependencies, instantaneous cold boot, and rock-solid stability.

🤫

Total Silence Policy

Strictly zero audio assets and zero sound APIs linked. No system beeps, no chimes. A quiet, unobtrusive utility built for focused creators and developers.

🛡️

Transparent Security

TLS Leaf Certificate Pinning locks peer connections without relying on Apple cloud credentials. Bounded constant $O(1)$ memory streaming through POSIX ODC CPIO.

How It Works

The AirDrop Protocol Pipeline

How AirDrop Wheel 2 communicates with nearby Apple devices peer-to-peer.

01

AWDL Interface Binding

Binds directly to awdl0 (Apple Wireless Direct Link) with peer-to-peer IPv6 multicast discovery.

02

DNS-SD Bonjour Browsing

Scans _airdrop._tcp services and resolves target device models (iPhone, MacBook, iPad) while filtering the local host.

03

TLS Handshake & Leaf Pinning

Initializes a secure TLS session via POST /Discover and pins the recipient's leaf public key to prevent MITM attacks.

04

CPIO Chunked Streaming

Streams standard POSIX ODC CPIO archives in 64 KiB chunks over POST /Upload, maintaining $< 15\text{MB}$ memory footprint.

Get Started

Install AirDrop Wheel 2

Compatible with all Macs running macOS 14.0 Sonoma or later.

Download pre-compiled Universal binary for Apple Silicon and Intel:

Download Latest Release (.app)

1. Drag AirDrop Wheel 2.app into /Applications

2. Grant Accessibility and Local Network permissions when prompted

3. Set recipient device to "Everyone for 10 minutes"

Clone and compile using Xcode Command Line Tools:

git clone https://github.com/Manfredsun/airdrop-wheel.git
cd airdrop-wheel
bash scripts/build_release.sh

Output binary will be code-signed and available at dist/AirDrop Wheel 2.app.
